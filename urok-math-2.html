Урок 2: Уравнения

Квадратное уравнение — уравнение вида ax² + bx + c = 0 (a ≠ 0). Кубическое уравнение — вида ax³ + bx² + cx + d = 0 (a ≠ 0). Корень уравнения — значение переменной, при котором уравнение превращается в верное равенство.

Здесь — формулы дискриминанта, корней и теоремы Виета для обоих типов уравнений.

Содержание

  • Глава 1: Квадратное уравнение
  • Глава 2: Теорема Виета
  • Глава 3: Кубическое уравнение

Глава 1: Квадратное уравнение

Уравнение ax² + bx + c = 0:

  • Дискриминант: D = b² − 4ac
  • Корни: x₁,₂ = (−b ± √D) / (2a)
  • D > 0 — два действительных корня
  • D = 0 — один корень (кратный)
  • D < 0 — нет действительных корней

Глава 2: Теорема Виета

Если x₁ и x₂ — корни уравнения ax² + bx + c = 0, то:

  • x₁ + x₂ = −b / a
  • x₁ · x₂ = c / a

Глава 3: Кубическое уравнение

Уравнение ax³ + bx² + cx + d = 0:

  • Приведение: замена x = y − b/(3a) даёт вид y³ + py + q = 0
  • p = (3ac − b²) / (3a²), q = (2b³ − 9abc + 27a²d) / (27a³)
  • Дискриминант: Δ = (q/2)² + (p/3)³
  • Δ > 0 — один действительный корень, Δ = 0 — кратные корни, Δ < 0 — три действительных корня
  • Формула Кардано: y = ∛(−q/2 + √Δ) + ∛(−q/2 − √Δ)
  • Виета: x₁+x₂+x₃ = −b/a, x₁x₂+x₁x₃+x₂x₃ = c/a, x₁x₂x₃ = −d/a
