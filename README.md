# Проблема

Студенты колледжа «IT Москва» сталкиваются с тем, что учебные материалы с уроков (конспекты, справочные материалы, темы) **разрознены**: они хранятся в разных чатах, блокнотах, у каждого студента по-своему. Нет единого места, где можно быстро найти информацию по пройденной теме — особенно при подготовке к сдаче работ или экзаменов. Новые студенты также не имеют доступа к накопленным материалам.

**Конкретные следствия проблемы:**
- Перед сдачей работы приходится листать десятки сообщений в чатах и чужие тетради.
- Один и тот же конспект существует в нескольких версиях, часто неполных.
- Материалы теряются при смене устройства, выходе из чата, уходе студента.
- Нет единой структуры: каждый оформляет конспект по-своему.

# Задача

Создать единый веб-сайт (без бекенда), который **централизованно хранит и структурирует** учебные материалы по предметам и темам уроков колледжа, обеспечивая быстрый поиск и удобную навигацию по ним.

**Критерии успеха MVP:**
- Все материалы доступны из одного места.
- Навигация «Главная → Предмет → Урок → Глава» работает без ошибок.
- Новый урок добавляется по понятному шаблону за 5–10 минут.
- Сайт открывается в браузере без сервера и без интернета.

# Решение

Сайт **IT Moskow wiki** — статический веб-сайт, выполняющий функцию хранения и систематизации информации с уроков колледжа «IT Москва». Сайт выполнен в стиле минимализма.

**Ключевая идея:** материалы лежат в обычных HTML-файлах, связанных относительными ссылками. Никакой базы данных, никакого сервера — открыл `index.html` в браузере и пользуешься.

# Функционал сайта

### Главная страница
- Заголовок сайта и краткое описание.
- Кнопки-карточки для перехода на страницы с предметами.

### Страницы с предметами
- Заголовок предмета и его описание.
- «Хлебные крошки»: Главная / Название предмета.
- Кнопки-карточки для перехода по темам уроков и включённым в них справочным материалам.
- Возможность перехода на главный экран.

### Страница с уроком
- «Хлебные крошки»: Главная / Предмет / Урок.
- Возможность перехода на главный экран.
- В верхней части урока — краткая справка по теме (1–2 абзаца).
- Оглавление с якорными ссылками и возможность перехода по главам.
- Разделение на главы с заголовками `<h2>`.
- Кнопка «↑ Наверх» для быстрого возврата к началу урока.

### Общие элементы
- Единая навигационная панель (header) на всех страницах.
- Единый CSS-файл для всех страниц.
- Кнопки «← К предмету» и «← На главную» в конце каждого урока.

# Реализация в MVP

- **Стек:** только HTML + CSS. Без JavaScript, без бекенда, без фреймворков.
- **Структура:** иерархия «Главная → Предмет → Тема/Урок → Главы».
- **Хранение данных:** материалы размещаются непосредственно в HTML-разметке страниц. Новые уроки добавляются через код: создание новой HTML-страницы по шаблону + добавление ссылки на неё в список тем предмета.
- **Навигация:** внутренние относительные ссылки между страницами, оглавление внутри уроков (якорные ссылки `<a href="#glava-1">`), кнопка «Наверх» (якорь `#top` на `<body>`).
- **Дизайн:** минималистичный, светлый, единый для всех страниц — спокойные цвета, скруглённые карточки, много воздуха, читаемый шрифт.
- **MVP:** без мобильной версии — верстка рассчитана на десктоп.

**Структура файлов проекта:**
```
it-moskow-wiki/
├── index.html            — главная (список предметов)
├── predmet-web.html      — предмет «Сети и интернет» (4 урока)
├── predmet-math.html     — предмет «Математика» (3 урока)
├── urok-1.html           — Адресация в интернете
├── urok-2.html           — Модель OSI и TCP/IP
├── urok-3.html           — HTTP и TCP
├── urok-4.html           — Локальная сеть (LAN)
├── urok-math-1.html      — Степени и корни
├── urok-math-2.html      — Уравнения
├── urok-math-3.html      — Функции
├── style.css             — общие стили
└── README.md             — инструкция по добавлению уроков
```

**Как добавить новый урок (кратко):**
1. Скопировать `urok-1.html` → переименовать в `urok-N.html`.
2. Заменить `<title>`, `<h1>`, справку, пункты оглавления и текст глав (следить, чтобы `id` глав совпадали со ссылками в оглавлении).
3. В странице нужного предмета добавить карточку-ссылку на новый урок.

**Что уже реализовано:**
- Работающая иерархия «Главная → Предмет → Урок → Глава» без единой ошибки в ссылках.
- Два предмета: «Сети и интернет» (4 урока) и «Математика» (3 урока).
- Единый минималистичный дизайн на всех страницах.
- «Хлебные крошки» и кнопки возврата на всех уровнях.
- Оглавление и якорные ссылки внутри уроков.
