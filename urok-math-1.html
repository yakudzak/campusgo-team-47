Урок 1: Степени и корни

Степень — произведение нескольких одинаковых множителей: aⁿ = a · a · … · a (n раз). Число a называется основанием, n — показателем. Корень — обратная операция: квадратный корень из a — это неотрицательное число, квадрат которого равен a.

В этом уроке — краткая шпаргалка по свойствам степеней, квадратных и кубических корней.

Глава 1: Свойства степеней

Для a > 0 (или при нечётных n для любого a):

  • aᵐ · aⁿ = aᵐ⁺ⁿ
  • aᵐ / aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐⁿ
  • (a · b)ⁿ = aⁿ · bⁿ
  • (a / b)ⁿ = aⁿ / bⁿ
  • a⁰ = 1, a⁻ⁿ = 1 / aⁿ
  • aᵐ/ⁿ = ⁿ√(aᵐ)

Глава 2: Квадратные корни

Для a ≥ 0:

  • √a · √b = √(a · b)
  • √(a / b) = √a / √b (при b > 0)
  • (√a)² = a, √(a²) = |a|
  • √(a²b) = |a| · √b
  • √a · √a = a
  • Важно: √(a + b) ≠ √a + √b

Глава 3: Кубические корни

Для любого a:

  • ∛a · ∛b = ∛(a · b)
  • ∛(a / b) = ∛a / ∛b (при b ≠ 0)
  • (∛a)³ = a, ∛(a³) = a
  • ∛(−a) = −∛a
  • ∛(a³b) = a · ∛b
