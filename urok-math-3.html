Урок 3: Функции

Функция — правило, по которому каждому значению x из области определения сопоставляется единственное значение y. Область определения D(y) — множество допустимых x, область значений E(y) — множество значений y.

В этом уроке — краткие свойства линейной и квадратичной функций, параболы и гиперболы.

Глава 1: Линейная функция

Линейная функция — y = kx + b. График — прямая. k — угловой коэффициент (тангенс угла наклона), b — ордината точки пересечения с осью Oy.

  • D(y): x ∈ ℝ; E(y): y ∈ ℝ (при k ≠ 0)
  • Монотонность: k > 0 — возрастает, k < 0 — убывает, k = 0 — постоянна
  • Нуль: x = −b/k (при k ≠ 0)
  • Чётность: нечётная только при b = 0
  • Пересечения: с Oy — (0, b); с Ox — (−b/k, 0)
  • Экстремумов нет, неограниченна

Глава 2: Квадратичная функция и парабола

Квадратичная функция — y = ax² + bx + c (a ≠ 0). График — парабола: a > 0 — ветви вверх, a < 0 — вниз. Парабола y = ax² — частный случай с вершиной в (0, 0).

  • D(y): x ∈ ℝ
  • Вершина: x₀ = −b/(2a), y₀ = c − b²/(4a)
  • Ось симметрии: x = −b/(2a)
  • Монотонность: при a > 0 убывает на (−∞, x₀], возрастает на [x₀, +∞); при a < 0 — наоборот
  • Экстремум: минимум при a > 0, максимум при a < 0, в вершине
  • Нули: x = (−b ± √D)/(2a), D = b² − 4ac
  • Чётность: чётная только при b = 0
  • E(y): при a > 0 — [y₀, +∞); при a < 0 — (−∞, y₀]
  • Чем больше |a|, тем «уже» парабола

Глава 3: Гипербола

Гипербола — график обратной пропорциональности y = k/x (k ≠ 0). Две ветви; оси координат — асимптоты (прямые, к которым график приближается, но не пересекает).

  • D(y): x ≠ 0; E(y): y ≠ 0
  • Монотонность: k > 0 — убывает на (−∞, 0) и на (0, +∞); k < 0 — возрастает на каждом из промежутков
  • Чётность: нечётная (симметрия относительно начала координат)
  • Нулей нет, экстремумов нет, неограниченна
  • Расположение: k > 0 — I и III четверти; k < 0 — II и IV четверти
  • Асимптоты: вертикальная x = 0, горизонтальная y = 0
